# 🏦 ဘဏ္ဍာစိုး (Bandasoe)

ဝင်ငွေ၊ ထွက်ငွေ၊ စုငွေ စာရင်းမှတ်တမ်းတင်နိုင်တဲ့ **Offline-first PWA**။

![No Backend](https://img.shields.io/badge/backend-none-10b981)
![License](https://img.shields.io/badge/license-MIT-blue)

---

## ✨ Features

- **၃ မျိုး မှတ်တမ်း** — ဝင်ငွေ / ထွက်ငွေ / စုငွေ
- **စုငွေ Model** — လက်ထဲနဲ့ စုငွေ သီးသန့် track၊ စုငွေကနေ ထုတ်သုံးလို့ရ
- **Validation** — လက်ကျန်ငွေ မလုံလောက်ရင် သတိပေး
- **Charts** — Pie + Bar + Line (၆ လ လမ်းကြောင်း)
- **Excel Export** — ဒီလ / အားလုံး + Summary sheet
- **Dark Mode**
- **Offline** — Service Worker cache
- **Installable** — Home Screen မှာ App အဖြစ် ထည့်လို့ရ
- **No Backend** — Data အားလုံး `localStorage` မှာ (privacy ✅)

---

## 🛠 Tech Stack

| Layer | Tech |
|-------|------|
| Markup | HTML5 |
| Styling | Tailwind CSS (CDN) + Custom CSS |
| Logic | Vanilla JavaScript (ES6+) |
| Charts | Chart.js 4 |
| Excel | SheetJS (xlsx) |
| Storage | localStorage |
| PWA | Manifest + Service Worker |
